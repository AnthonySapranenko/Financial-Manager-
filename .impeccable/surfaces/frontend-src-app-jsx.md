# Finance Manager: main screen

Mode: operate. One screen: log a transaction in seconds, read this month's totals, review spending, budgets, and history. Phone (quick entry) and desktop (periodic review). Developer chose to run unattended; direction taken from the roll without a decision round.

## Direction contract

THESIS: The money screen as US banknote engraving: exact figures set like a note's denomination, refusing the category's grey dashboard of soft white cards.

OWN-WORLD: Pale currency-paper ground (green-grey, never cream), intaglio green-black ink, a back-green shell band, Treasury-seal green for income and United States Note red for expense. Bodoni Moda for headings and figures, system sans for controls. Hairline rules and double-rule frames, 2px corners, no shadows. Fills are fine diagonal line engraving.

STORY: The visitor sees the month's arithmetic, logs a purchase without scrolling, and checks which budgets are running low.

FIRST VIEWPORT: Green shell band with the name and month. Below it, the totals plate: income − expenses = balance, the balance at denomination scale inside a double-rule frame. Desktop: three columns (add form, transactions, the month's spending and budgets). Phone: plate, form, transactions, then the month.

FORM: banknote engraving, candidate 4 of 7, seed key da326708. Signature move: the engraved equation plate plus line-engraved meters; over-budget stamps itself in red. Raises: from the metro tiles, delete chrome so type carries hierarchy; from the ticket wallet, state stamps itself; from the Crouwel grid, figures align on a strict tabular column.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
